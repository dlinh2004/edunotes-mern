# EduNotes – Quản lý Ghi chú Học tập (MERN Stack)

## 📌 Giới thiệu
EduNotes là ứng dụng web giúp người dùng tạo, quản lý và theo dõi các ghi chú học tập một cách hiệu quả. Dự án được xây dựng bằng MERN Stack (MongoDB, Express.js, React, Node.js).

## 🚀 Chức năng chính
- ✏️ CRUD ghi chú (tiêu đề, nội dung, môn học)
- 🔎 Bộ lọc theo môn học hoặc ngày tạo
- 📆 Phân trang danh sách ghi chú
- 📊 Thống kê số ghi chú theo môn học
- ✅ Lọc ghi chú đã hoàn thành

## 🛠️ Công nghệ sử dụng
- **Frontend:** React + Vite + Tailwind CSS  
- **Backend:** Node.js + Express.js  
- **Database:** MongoDB

## 📂 Cấu trúc thư mục
client # Giao diện người dùng
server # API backend và kết nối MongoDB
